# 📋 Jadwal Kegiatan - Kabid Bina Marga

Aplikasi PWA untuk mencatat dan memantau jadwal kegiatan Kepala Bidang Bina Marga.

## 🚀 Fitur

- ✅ **Tambah, edit, hapus** kegiatan dengan mudah
- ✅ **Kalender bulanan** untuk melihat jadwal
- ✅ **Update status** kegiatan (Terjadwal/Berlangsung/Selesai/Ditunda/Dibatalkan)
- ✅ **PWA Ready** - Bisa diinstall di HP seperti aplikasi native
- ✅ **Offline Support** - Bisa diakses tanpa internet (cache)
- ✅ **Responsive** - Tampilan optimal di HP, Tablet, dan PC
- ✅ **Dark Mode** - Mendukung tema gelap
- ✅ **Data tersimpan di Google Sheets** - Aman dan terpusat

## 📱 Cara Install di HP

1. Buka URL aplikasi di browser HP (Chrome/Safari)
2. Klik tombol **Install** di pojok kanan header
3. Atau buka menu browser (3 titik) → "Tambahkan ke layar utama"
4. Aplikasi akan muncul seperti aplikasi native di home screen

## 🖥️ Cara Install di PC (Chrome)

1. Buka URL aplikasi di Chrome
2. Klik ikon **Install** di address bar (sebelah kanan URL)
3. Atau klik tombol **Install** di header aplikasi

## 🔧 Teknologi

- **Frontend**: HTML, CSS, Vanilla JS
- **Backend**: Google Apps Script
- **Database**: Google Sheets
- **PWA**: Manifest + Service Worker
- **Hosting**: GitHub Pages

## 🔗 Deploy

### 1. Backend (Google Apps Script)
1. Copy `Code.gs` ke Google Apps Script
2. Deploy sebagai Web App
3. Copy URL Web App

### 2. Frontend (GitHub Pages)
1. Upload semua file ke repository GitHub
2. Ganti `API_URL` di `index.html` dengan URL Web App
3. Aktifkan GitHub Pages di Settings
